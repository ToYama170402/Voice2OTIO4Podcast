# システム仕様書

## 1. システム概要

本システムは、入力された音声ファイル群（話者ごとに1ファイル）に対して音声認識、NLPに基づく字幕単位の分割、カット候補の自動判定を行い、DaVinci Resolve向けにクリップが相互リンク（グループ化）された状態のタイムラインデータ（`.otio`）を生成する自動化パイプラインである。

ムダな区間（フィラー・無音・言い直し等）を物理的に削るリップルカットは行わず、元の時間軸を完全に保持したまま、字幕の境界線に合わせて音声ファイルを連続スライス配置する。カットの最終判断は編集者が行う。

## 2. 主な機能・仕様

1. **エンドツーエンド処理**: 音声ファイルの入力からOTIOファイルと字幕（SRT）の出力までを一元処理する。
2. **文字起こしバックエンド**: `faster-whisper`（既定）と `SenseVoiceSmall`（sherpa-onnx）を `--backend` で選択できる。どちらも単語タイムスタンプ付きの結果を返す。
3. **NLP字幕分割**: 単語タイムスタンプと形態素解析（SudachiPy）を用い、表示文字数・時間の制限に収まるよう字幕を文節単位で分割する。境界は文節の先頭にのみ置き、単語や文節の途中では切らない。フィラーは独立した字幕・スライスとして切り出す。
4. **カット候補判定**: 無音（0.4秒超の間隔）、フィラー、低信頼度（`no_speech_prob > 0.8`）、言い直し（直後の発話に言い直された発話、発話冒頭の繰り返し）を候補として判定する。言い直しはトークン列から試行の範囲を特定し、試行だけを独立スライスにする。
5. **音響フィラー候補（任意）**: `--acoustic-fillers` 指定時は、文字起こしとは独立に音声信号からフィラー候補を検出し、音声クリップへマーカーとして付与する。文字起こしにフィラーが残らないバックエンドでも候補を提示できる。
6. **無断短縮なし（全時間保持）**: 音声データはカットせずタイムライン上にすべて配置する。ムダな区間には専用の目印トラックにフラグクリップとマーカーを配置する。
7. **DaVinci Resolve 自動リンク連携**: OTIOの `metadata.Resolve_OTIO.Link Group ID` を活用し、インポート時点で「目印クリップ」「字幕クリップ」「スライス音声クリップ」の3要素が自動でリンクされた状態を再現する。
8. **キャッシュと再開**: 文字起こし結果は入力ファイルごとにキャッシュし、再実行時は完了分を再利用する。SenseVoiceではチャンク単位の途中経過も保存し、途中から再開できる。
9. **音声変換（SenseVoice）**: 入力音声は推論前に16kHzモノラルWAVへ変換する（PyAVによるストリーミング変換、結果はキャッシュ）。これによりm4a等の形式も扱える。

### 実装契約

- 複数入力は1ファイル = 1話者 / 1音声ソースとして扱い、入力順に独立した3層トラックを生成する。複数トラックのファイルはトラックごとに1音声ソースとして展開する。1トラック内の話者分離は行わない。
- 正常区間は字幕・音声をリンクし、カット候補区間だけ目印・字幕・音声の3要素をリンクする。
- 各音声ソースの先頭から末尾までをOTIO上で保持し、字幕間・先頭・末尾のギャップを欠落させない。
- バックエンドは単語タイムスタンプを秒単位で返す必要がある。取得できない推論結果はエラーとして処理を止める。

## 3. 入出力

| 区分 | 内容 |
| --- | --- |
| 入力 | 音声ファイル（話者ごとに1ファイル、または複数トラックのファイル）。形式はバックエンドが読み込めるもの（SenseVoiceでは変換層によりm4a等も可） |
| 出力（主） | OpenTimelineIO（`.otio`）。既定30fps、シーケンス名は既定 `Podcast_Timeline` |
| 出力（副） | 字幕ファイル（`.srt`）。出力OTIOと同じ場所に生成（`--srt-output` で変更可） |
| キャッシュ | `~/.cache/podcastpreprocessor/` 配下（文字起こし、変換済み音声、SenseVoiceモデル） |

## 4. 採用フォーマット

- **フォーマット**: **OpenTimelineIO (.otio)**
- **選定理由**: JSONベースで拡張性が高く、DaVinci Resolveのネイティブメタデータ構造（`Resolve_OTIO`）を通じて、FCP7 XMLでは不可能な「インポート時点でのクリップ間リンク」がサポートされているため。
